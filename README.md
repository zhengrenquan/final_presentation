# 唐纳德·特朗普推文分析仪表盘

## 项目简介
本项目是一个基于 Streamlit 的数据分析仪表盘，旨在对唐纳德·特朗普的推文进行深入分析和可视化展示。通过本应用，用户可以探索推文的时间分布、互动热度、关键词频率等多方面信息。

## 主要功能
- **年份选择**：用户可选择特定年份，查看该年度的推文分析。
- **关键词搜索**：支持输入关键词，筛选包含该词的推文内容。
- **年度推文数量统计**：以柱状图展示每年的推文发布数量。
- **互动分布分析**：统计推文的点赞数与转发数，展示整体互动热度分布。
- **高频词统计**：统计推文内容中的常用词汇，剔除用户与话题标签，突出文本核心词。
- **高互动推文展示**：列出每年互动量最高的前十条推文，便于快速了解热门内容。

## 使用方法
1. 准备推文数据文件（CSV 格式），并确保包含 `date`、`content`、`retweets`、`favorites` 等字段。
2. 按需修改 `final_presentation.py` 文件中的数据路径。
3. 在命令行运行 `streamlit run final_presentation.py` 启动仪表盘。
4. 在网页界面选择年份、输入关键词，并浏览各项分析结果。

## 环境依赖
- Python 3.7 及以上
- Streamlit
- pandas
- matplotlib
- numpy

安装依赖：
```bash
pip install -r requirements.txt
```

## 数据说明
数据文件需包含以下主要字段：
- `date`：推文发布时间
- `content`：推文内容
- `retweets`：转发数
- `favorites`：点赞数
